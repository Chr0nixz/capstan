# 远程文件、传输与恢复

M2 的文件工作流已有工程实现，当前提供审查构建。完整性能、Explorer/实际编辑器交互和 v0.2 候选尚未验收；当前结果和交付见 [M2 收尾](agent/M2-CLOSEOUT.md)，维护者操作清单见 [M2-MANUAL](agent/M2-MANUAL.md)。本文说明当前行为，不代替验收记录。

## 浏览和修改

连接已保存的 SSH 主机后，“远程文件”面板随当前 SSH 标签显示。每个标签保留自己的目录；本地 PowerShell/WSL 标签不显示远程文件。面板支持右侧/下方停靠、调整尺寸和折叠，最近保存的布局供新标签和下次启动使用。

在路径栏输入远程绝对路径，或使用“上级目录”“刷新”“隐藏文件”和“复制路径”。新建文件/目录、重命名和权限操作以当前选中项为目标。权限使用八进制，修改目录权限不会递归修改其内容。服务器拒绝 SFTP 时，SSH 终端仍可单独使用。

删除目录会先检查并显示范围。确认“删除此目录树”后，逐项显示已删除、失败或保留的结果；符号链接只删除链接本身。“取消剩余删除”停止后续条目，当前已发出的请求需要等服务器返回。已经完成的删除不能撤销，整个目录树也不能整体回滚。内容变化会要求重新确认；超出预览界限的树需要分成较小范围处理。

## 上传、下载与资源管理器

选择“上传文件”或“上传文件夹”，通过 Windows 选择器授予来源；下载先选远端条目，再选择本地目的地。也可把 Explorer 中的文件/文件夹拖到当前可见的远程文件面板，上传到面板显示的目录。

拖出需要先准备本地副本：

1. 选中远端文件或目录，点击“准备拖出到资源管理器”。
2. 处理目录和名称冲突，等待状态变为“可以拖出”。
3. 将“拖到资源管理器”控件拖到 Explorer 目的目录。
4. 等待 Explorer 完成复制，再在“资源管理器导出”中选择“删除导出副本”，确认“复制已完成，删除副本”。

拖出是复制，不会移动远端原件。Escape 取消拖拽会保留准备好的副本；清理拒绝时也保留它。准备好的拖出授权五分钟后到期，控件会变为不可拖拽的保留副本；可重新准备一次导出。重启后保留的导出副本只有本地清理入口，不会自动上传或重新开始拖拽。

复制文件夹会保留空目录。已有目录需明确合并；文件与目录类型冲突需改名或跳过。跳过一个目录也跳过其内容。Windows 无法表达的名字、大小写碰撞等会要求处理，改名只影响本次复制目标。普通同名文件另行选择覆盖、另存为或跳过；批量选择仅适用于本批次已检查且未变化的目标。目标后来变化会再次询问。递归复制不跟随符号链接，不支持的类型会拒绝。

“传输任务”显示进度、速度、剩余时间和失败原因，默认最多三个活动任务。暂停后等待已发出请求收敛，再继续；取消不截断已有正式目标。来源 SSH 标签关闭后，仍有租约的后台传输可以继续。文件夹的部分失败可能留下已创建目录和已成功文件，应按逐项结果检查，不能把整个文件夹视作一次原子操作。

并行传输继续复用原 SSH 连接。某个传输通道失败时，其他仍在线的传输和终端可以继续；受影响任务需显式重试。服务器限制并发通道时，任务会等待可用通道。取消后的服务器响应与文件句柄清理仍可能需要等待，退出会一并收敛。

## 中断、重试与残留

网络断开后，Capstan 会探测并按退避策略重连原 SSH 连接。当前进程内仍持有目的地授权的中断下载，会在连接恢复后自动重绑；只有原主机/身份策略、远端元数据、部分文件大小和已完成前缀都核验匹配后才续传。正式目标已存在时仍需再次确认覆盖。此自动恢复不适用于上传、已释放本地授权的下载或进程重启后的任务；上传必须重新选择来源，重启后的下载须在恢复入口重新选择原最终目标。重连不会恢复旧 shell 或重放终端输入。

异常退出后，“中断传输文件”只列出 Capstan 自己记录的残留，不扫描认领任意 `.partial`。它不恢复整个排队队列，也不会自动认证、续传或删除。

恢复记录使用原 Windows 用户的加密能力保存。重启后应使用同一用户和原数据目录；换电脑、丢失用户加密密钥或复制记录到其他目录，可能无法读取记录，但不会因此删除残留文件。旧明文记录迁移为加密记录后仍需人工检查，不会获得新的续传或清理权限。

| 状态或操作 | 如何处理 |
| --- | --- |
| 继续上传 | 重连匹配身份的原主机，在新选择器中选原来源，等待前缀核验后续传；上传不会自动重绑。 |
| 继续下载 | 当前进程内仍授权的中断下载会在连接恢复后自动重绑，核验目标身份、元数据、partial 大小和前缀后才续传，已有正式目标仍需确认覆盖。进程重启后，重新选择原最终目标的目录和文件名，即使正式文件尚未存在；不要选择 `.partial` 文件。选错目标会保留残留。 |
| 删除残留 | 上传仅在显示“需要清理，无法续传”且保存了原属性基线时提供；普通可续传上传只提供续传，并提示先人工检查远端残留。下载仍要求重新选择原最终目标。明确确认后只清理已核验的 partial，正式目标保留；取消确认不会删除。 |
| 需要清理，无法续传 | 传输失败且临时文件未能删除。记录跨重启保留，只提供显式清理；远端临时文件须仍匹配记录的属性，本地临时文件须通过新选择器核验原身份。重新传输请从文件面板发起。 |
| 需人工检查 | 旧记录缺少原文件身份、来源基线或原授权信息，或者残留的归属无法确认，不能安全自动恢复/清理。保留 partial，在原主机或本地检查并另行保存需要的数据；不要修改恢复记录来强行启用操作。 |
| 残留已变化、缺失或记录不可读 | 保留提示和仍可取得的数据，核实原来源、目的地及连接身份。不要把当前文件属性当成原始基线。 |

恢复失败、提交结果不确定或仍有临时文件时，先刷新检查正式目标和残留，再决定下一步。SFTP 的检查后重命名/删除不能阻止所有外部并发修改；相同大小和时间的内容替换也不一定能通过属性检查发现。

## 使用本地编辑器

双击支持的常规文本文件，通过原生选择器配置本地编辑器。当前上限为 8 MiB，支持有效 UTF-8 和带 BOM 的 UTF-16；编辑保留原字节编码/换行，不执行远端文件。文件正文保存在受控本地副本中，实际编辑器会读取该副本。

保存后等待文件稳定和回传完成，再检查远端版本。编辑器复用已有进程或启动进程退出不表示编辑已结束；关闭来源标签、切换标签或折叠面板也不结束编辑。使用全局“远程编辑”入口继续处理。

远端被其他客户端改动时，先保留双方，再选择另存为、明确覆盖，或保留远端并放弃本地修改。覆盖确认后远端再次变化会重新询问。服务器不支持安全替换时，使用另存为或本地导出。

结束编辑前先在实际编辑器中关闭文档，再通过 Capstan 结束、导出、明确放弃，或选择“保留文件供下次恢复”。取消导出、启动失败、回传失败和清理失败都会保留可处理的副本。编辑器尚未保存的内存内容不在 Capstan 的恢复范围内。

异常退出后可发现本应用拥有且不被其他活动实例占用的编辑副本；可导出、保留或明确放弃，不自动回传。远端临时文件的恢复记录需要原 Windows 用户的加密能力；重新连接匹配身份后，只能显式核验并清理，不会重放文档上传。无法核验的文件和未知备份保留供检查。

## 跟随目录与 Shell 集成

手动浏览无需安装集成。“跟随终端”仅使用当前标签经过校验的目录提示；手动打开目录会关闭跟随，重新开启后才采用最近有效提示。提示是远端发来的不可信信息，不赋予文件写入或本地访问权限。

当前安装目标为 Linux Bash/Zsh。在远程文件面板显示隐藏文件，选择具体配置文件（如 `.bashrc` 或 `.zshrc`），进入“Shell 集成”，选安装/卸载，先“预览”再“应用集成”。首次安装备份原内容；重复安装不重复添加区块。卸载只移除可识别且未被改动的 Capstan 区块，保留标记外用户内容；配置变化需要重新预览，异常标记需人工处理。不要用旧备份覆盖后来新增的配置。

Shell 输出的主机名和连接地址不一致时，可在“Shell 主机别名”中明确绑定已确认属于此主机的名称。别名仅作用于该终端，不自动信任其他主机；未绑定或非法提示保留当前目录。

## 锁定、退出与支持边界

默认锁库允许已授权连接和文件任务继续；已显示的远端内容和外部编辑副本不会因此消失。选择锁定时断开全部连接会停止相关工作，未回传修改仍需保留或导出。

退出时先处理编辑副本，再决定继续等待或取消剩余文件操作。已经开始的提交/删除等待实际结果；排空超时会保持窗口打开，避免把未回收状态当作退出成功。

当前支持范围为已验证的 Windows x64。UNC/设备路径、reparse point 和不支持的远端文件名/类型需要其他目的地或人工处理。文件提交不是目录项断电持久性的保证；普通传输不承诺保留原权限和时间，编辑回传会保留原权限。完整兼容范围与限制见 [M2-SFTP-COMPAT](agent/M2-SFTP-COMPAT.md)。
