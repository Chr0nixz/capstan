## 首次复核：P2 · 资源管理器入口无法打开盘符根目录

修复前位置：`hooks.nsh:10`、`hooks.nsh:14`。注册命令的 `--cwd "%V"` 在 `%V` 为 `C:\` 时产生 `--cwd "C:\"`。Windows argv 解析会让末尾反斜杠转义结束引号，第三个参数变成 `C:"`；core 随后返回 `Focus`。已有实例只被聚焦，不会新建根目录终端；首次启动也丢失该目录请求。其他以反斜杠结尾的目录参数有同样问题。

复核使用真实 Rust 子进程的 argv 和当前 core 解析器，没有改注册表。探针源码为 `target/m4-3-c-args.rs`，只收集 `std::env::args().skip(1)` 并打印 `parse_launch_args` 的结果。在仓库根目录重跑：

```powershell
$coreLibrary = Get-ChildItem target/debug/deps/libcapstan_core-*.rlib |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
rustc --edition=2021 target/m4-3-c-args.rs -L dependency=target/debug/deps `
    --extern "capstan_core=$($coreLibrary.FullName)" -o target/m4-3-c-args.exe
$start = [Diagnostics.ProcessStartInfo]::new()
$start.FileName = (Resolve-Path target/m4-3-c-args.exe).Path
$start.UseShellExecute = $false
$start.RedirectStandardOutput = $true
foreach ($raw in @('--local --cwd "C:\"', '--local --cwd "C:\Windows"', '--local --cwd "C:\\"')) {
    $start.Arguments = $raw
    $child = [Diagnostics.Process]::Start($start)
    $child.WaitForExit()
    $raw
    $child.StandardOutput.ReadToEnd()
    $child.Dispose()
}
```

实际结果：

| 原始命令行 | core 结果 |
| --- | --- |
| `--local --cwd "C:\"` | `Focus`，失败 |
| `--local --cwd "C:\Windows"` | `Local { … working_directory: Some("C:\\Windows") }` |
| `--local --cwd "C:\\"` | `Local { … working_directory: Some("C:\\") }` |

建议修正命令中目录末尾反斜杠的引用方式，并增加启动真实子进程检查 argv 的回归用例。[安装检查:86](../../scripts/Test-M1Install.ps1#L86)修复前只比较注册表字符串，期待的也是相同错误模板，因此即使实装检查通过也覆盖不到此问题。完整资源管理器点击尚未实测；上述失败发生在进入应用路由之前。

## 首次复核：P2 · Quake 保存外框尺寸，却按客户区尺寸恢复

修复前位置：`quake.rs:232`、`quake.rs:270`。`toggle_window` 保存 `outer_size()`，`restore_window` 把这个值直接交给 `set_size()`。当前锁定的 Tauri runtime 将 `SetSize` 转发成 Tao 的 `set_inner_size`。无边框窗口仍有原生阴影边距，两者并不相等。关闭 Quake 后窗口会变大，重复进入、退出还会累积偏差。

复核使用工作区编译出的 Tao 0.37.1，创建独立的隐藏窗口，采用与应用相同的无装饰、透明窗口设置。探针记录外框尺寸，调整为 Quake 尺寸，再把已记录的外框尺寸传给客户区尺寸 API；不打开终端或读取应用数据。源码为 `target/m4-3-c-window.rs`，日志为 `target/m4-3-c-window.log`。重跑：

```powershell
$taoLibrary = Get-ChildItem target/debug/deps/libtao-*.rlib |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
rustc --edition=2021 target/m4-3-c-window.rs -L dependency=target/debug/deps `
    --extern "tao=$($taoLibrary.FullName)" -o target/m4-3-c-window.exe
& target/m4-3-c-window.exe
```

实际结果：初始客户区 `800×600`、外框 `818×610`；按修复前实现恢复后，客户区变成 `818×610`、外框变成 `836×620`，`matches_original=false`。外框宽、高分别多出 **18、10 像素**。这是底层窗口 API 探针的实测值，未声称已完成完整 Capstan 桌面操作。

同一探针还测到：窗口最小化后，`outer_position()` 为 `(-32000, -32000)`，`outer_size()` 为 `199×34`。修复前代码在第一次热键触发时直接保存这些值，没有排除最小化状态，之后关闭模式会拿临时图标几何恢复。完整应用在最小尺寸约束下的最终表现仍需手测。

初次复核建议使用一致的尺寸语义，并保存普通窗口的有效还原位置，覆盖“最小化后首次呼出”和原先最大化的情况；不需要改变既定的复用主窗口方案。补充回归时应断言窗口 API 的实际几何，修复前的 `quake_height_is_bounded_to_the_work_area` 只测试百分比计算。
