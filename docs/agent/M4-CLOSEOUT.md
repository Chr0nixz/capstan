## 验收复核

2026-11-05 独立复跑交付检查、布局与安全、原生 crate、依赖许可和隔离更新回滚，均通过；`cargo deny` 使用当日离线漏洞库。复核后修复三处：

- 恢复早于 KEK slot 的备份后，失效清理删除在当前 DEK 下仍能认证的 Hello 密钥，不再留下孤立 Passport 密钥；损坏或属于其他 Vault 的 sidecar 仍不触发删除。
- `ssh://` 匹配已保存主机改由 Rust 的 `match_launch_hosts` 完成，按 Vault 地址规范化比较大小写、末尾点和 IPv6 写法。
- 用户名含 `@` 或 `%` 时，链接与多主机选择按 URL 形式编码显示，如 `alice%40corp@host:22`。

修复后格式、三组 Clippy 通过；workspace 测试 478 项、运行时 33 项、全特性 519 项、UI 532 项通过。`vendor/ssh-key` 钉住的 `crypto-bigint 0.7.6` 已被撤回，升级属于 M4 范围外的 vendor 依赖，另行处理。
