- 扩展 `crates/capstan-ssh/tests/real_sshd.rs`，新增 `tests/real_sshd/forwarding.rs`：在已经认证并验证临时信任的同一 transport 上持有连接池租约，建立 `-R`、`-L` 和 SOCKS5 `-D`。每条数据路径核对 48 KiB 二进制往返和半关闭；停止 `-L` 后验证端口释放、精确流量计数、`-R` / `-D` 及同连接 shell 继续可用，最后等待隧道停止、活动连接归零并断开 transport。
- OpenSSH 主机指纹变化用例仍先阻断；未配置 `CAPSTAN_TEST_SSHD` 时保留明确 skip，不尝试外部连接。转发回环不依赖远端临时文件或辅助服务，片段、凭据和终端正文不进入日志。
