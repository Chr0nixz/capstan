## 待办

按对日常使用的影响排序：

1. **高 RTT 下传输时 SSH 输入卡顿。** r5 正式轮的部分输入回显停顿 2–3.5 秒；原因未定位，属于日常体验问题，可按实际影响排期。
2. **刷屏标签的本地回显尾延迟。** r6 的一次前台 M1 测量为 111.1 ms；相较 r5 的 198.8 ms 已下降，仍值得在日常使用中观察。
3. **本地终端吞吐。** r6 单标签 100 MiB 为 21.91 MiB/s，超过此前记录的 21.69 MiB/s参考值；性能数字不作为交付或发布门槛。
4. **测量和打包脚本的默认输出目录**仍是 `docs/agent/baselines/*/raw/`，改为默认写到 `target/`。
5. **CI/CD 上线**：合并后演练 Windows x64 安装和便携启动，再启用 `main` 门禁。正式 tag 由维护者决定。
