# M4-2 交付记录

2026-11-04。终端右键菜单、配色导入、任务栏进度和后台通知已实现，待 Windows 桌面验收。

## 修改内容

- 终端菜单支持右键、Shift+右键、Shift+F10 和菜单键。远端启用鼠标上报时，普通右键由 xterm 处理。旧式、SGR 和 SGR 像素鼠标报告均发往原窗格。菜单复制读取当前选区，粘贴复用 xterm 的 bracketed paste、多行确认和广播规则。清屏只作用于本地显示与回滚。选中即复制默认关闭，启用后只写剪贴板。
- 设置的「桌面」页可导入 Windows Terminal JSON 和 iTerm2 XML 配色。Rust 通过原生选择器读入最多 1 MiB，WebView 收到校验后的色板与预览令牌。标准 Apple plist 声明仅作文本识别，自定义 DTD 和实体会被拒绝。确认后原子保存到 `terminal-themes.json`，最多 32 个主题、128 KiB。多配色文件逐项预览后一次保存，重名追加序号。
- 导入主题可重命名和删除，可用于主机配置与命令面板。主机保存 `custom:<uuid>`，缺少对应主题时渲染石墨配色并保留已保存的 ID。预览与设置默认值由 Rust 和 TypeScript 共同测试。
- 任务栏聚合当前批次的传输快照。目录扫描显示不确定进度，暂停和等待重连显示黄色，失败和待决冲突显示红色。队列按失败版本确认，仍可重试。Rust 每秒最多更新四次。
- 默认启用系统通知。后台单批达到 100 MiB 或 30 秒时通知完成或失败，按本轮成员的开始和结束时间判定。执行区间相交的成员一起统计，批次结束后发起的重试单独计时和计量。SSH 意外断开按连接代次去重，10 秒内合并。Toast 仅显示事件计数。便携版和缺少有效 AUMID 的环境静默降级。
- 经维护者授权，额外修改了 Vault 主机主题校验、传输命令的扫描状态接线、队列的失败确认，以及传输的 Rust 只读计时快照。

## 已知风险和未决问题

- Windows 11 安装版的通知横幅、任务栏颜色、WebView2 剪贴板和高对比度表现仍待桌面手测。默认开始菜单快捷方式被移动、删除或指向其他程序时，Toast 会静默降级。
- SGR 分流依赖当前固定版本 xterm 的鼠标入口。若升级后入口无法识别，开启鼠标上报的受管窗格会阻断无法区分的输入。
- 写入自定义主题 ID 后，只识别内置主题的旧构建可能拒绝该 Vault。若目录批次运行期间有新任务入队，队列保留上限可能淘汰该批次较早结束的条目，桌面聚合将按剩余快照计算。

## 手测清单

1. 在启用 SGR 鼠标的 vim 或 htop 中开启分屏广播，确认普通右键只作用于原窗格。再试 Shift+右键和 Shift+F10，用方向键和 Esc 验证焦点。试复制、选中即复制、清屏和广播下的多行粘贴。
2. 导入两种格式，在主机配置与命令面板应用。重启后检查保留情况，重命名并删除一个在用主题，确认终端回退为石墨。用带注释 JSON 验证导入报错。
3. 传输一个目录，观察扫描、运行、暂停、重连等待和失败状态。确认失败或解决冲突后检查红色进度清除，待传输结束后检查进度消失。
4. 在安装版后台运行大批传输并模拟传输失败和 SSH 断线，检查合并的 Toast。等一分钟再重试一个很小的失败项，确认短重试没有通知。前台、关闭通知、主动断开和便携版各试一次。
5. 启用 Win11 高对比度并关闭动画，仅用键盘完成菜单操作、切换设置和主题预览。
