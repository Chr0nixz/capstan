## 修改内容

- 启动参数和 `ssh://` 在 core 校验，限制为 8 个参数、每个 4096 字符。重复参数、无效目录、设备路径、ADS、非法端口和解码后的控制字符均回退到聚焦。URL 的路径、查询、片段和指纹参数不参与连接或信任。
- 单实例采用契约允许的本机命名管道。管道名按规范化数据目录派生，保留固定的应用标识；转发前核对服务端用户 SID，并拒绝远程管道客户端。第二次启动在创建窗口前转发原始参数并退出，首个实例重新解析。待处理请求最多 8 个。
- 前端只用请求 ID 打开外部指定目录。Rust 缓存最近使用的 256 个本地启动配置，分屏和重启可复用 ID；配置不写入设置。WSL 无法使用请求中的 Windows 目录时回落到默认目录并提示。界面依次处理启动请求，取消解锁或确认会丢弃请求；SSH 链接匹配多个主机时选择，未知主机先填写凭据并保存。
- NSIS hooks 在 HKCU 写入目录及目录背景的经典右键菜单，并把 Capstan 注册为可选的 SSH 处理程序。菜单和协议说明有中英文。卸载完成后按安装路径所有权标记清理自己的键，不覆盖现有 `ssh` 处理程序或 UserChoice。
- 原生跳转列表最多显示 6 个本地 Shell 任务。最近主机默认关闭，开启后最多 10 个，只有显示名和 `--host <uuid>`；设置只保存 UUID。连接成功、删除主机、覆盖导入、关闭选项和清除均有接线。发布列表在后台执行，便携版跳过。进程、列表和安装器快捷方式使用 `dev.capstan.app`。
- Quake 默认关闭、没有默认热键，高度默认 50%，可调 20–90%。Rust 校验组合键，拒绝单键、仅 Shift 和 Ctrl+字母。更换时先注册新键，注册或设置写入失败保留旧键。窗口在光标所在显示器工作区顶部显示或隐藏，关闭模式恢复原位置、大小和最大化状态。隐藏保留会话，释放 WebGL 并暂停状态采集；没有窗口动画。
- 补充共享 fixture、Rust/TS 测试、设置入口和安装脚本断言。`workspace.ts` 和 `terminal/transport.ts` 的前序接线已收回允许的启动适配器，两个文件相对任务前没有改动。新增依赖为固定版本 `tauri-plugin-global-shortcut = 2.3.1`。

## 复核加固

- **资源管理器根目录**：两处菜单的目录参数改为 `"%V/"`，防止盘符根目录或其他末尾反斜杠转义结束引号；不经过 shell，也不放宽 core 路径校验。安装脚本同步核对新模板。持久回归直接读取 hooks，用两个模板各启动 8 个真实 Rust 子进程，断言 argv、路径语法及真实存在目录的解析；覆盖根目录、空格、Unicode、UNC 和末尾分隔符，UNC 不访问网络。
- **Quake 几何恢复**：原生边界用成对的 `GetWindowPlacement` / `SetWindowPlacement` 保存和恢复普通窗口位置，保持 [Windows 的工作区坐标语义](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-windowplacement)，不再把外框大小传给客户区尺寸 API。最小化时读取正常还原矩形，并保留“最大化后最小化”的还原状态。捕获、恢复及窗口操作在主线程排序；设置保存期间的热键触发也不会覆盖新捕获的还原记录。未增加依赖。
- 原生测试对普通、最小化、最大化、最大化后最小化四种状态各做三轮实际变形、隐藏和恢复，断言外框、客户区、位置及最大化状态，并覆盖无效句柄。同版本 Tao 的隔离无边框透明窗口探针也通过：客户区恢复为 **800×600**、外框 **818×610**、位置 **(180, 160)**，四种状态一致。探针先等待初始非客户区布局稳定；不读取应用数据，不代表完整 Capstan 热键流程已手测。

## 手测清单

1. 再次启动应用，分别试无参数、`--local --cwd "C:\Windows"`、未知参数和 WSL 配置。确认只有一个同目录实例，目录及回退提示正确。
2. 同时运行安装版和两个不同数据目录的便携版，分别发送启动请求，确认不会互相转发。
3. 在干净普通用户环境安装、升级和卸载；在盘符根目录、含空格目录及 UNC 的目录和空白处使用经典菜单，分别检查首次启动和已有实例。确认可选 SSH 默认应用、原有 SSH 关联和卸载清理。
4. 点击已保存、重复匹配及未知主机的 SSH 链接；取消一次解锁和确认；未知主机保存后才连接，URL 指纹不影响信任流程。
5. 用任务栏打开 Shell；开启最近主机后连接、重启、删除、覆盖导入、清除并关闭选项。确认只显示显示名，锁库后点击先解锁。
6. 从请求目录打开本地标签，再分屏和重启，检查目录保持且现有会话不被替换。
7. 设置 Quake 热键，故意制造冲突并更换热键；普通、最小化、最大化及最大化后最小化各呼出并关闭三次，再还原为普通窗口，检查无尺寸累积偏差。跨显示器和 DPI 再试一次。
8. Quake 隐藏一分钟后恢复，确认 SSH、本地 Shell、传输和回滚保留，状态采集恢复；再用键盘、高对比度及 reduced-motion 检查新增界面。
