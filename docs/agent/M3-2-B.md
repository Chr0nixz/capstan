## 审查意见处理

- **C1：StrictMode 重复发送。** 每次命令面板运行生成独立请求 ID；片段面板在回调或发送前同步记录已消费请求，父组件只确认对应 ID。保留 StrictMode，覆盖初次打开、关闭后重新打开及同一片段的新请求；每次显式操作只投递一次。
- **C2：失败结果不可见。** 片段面板直接显示 App 的投递结果，包含失败窗格、稳定错误原因及不自动重放的提示；空广播目标也在面板内显示。发送返回 Promise，等待确认或投递时阻止重复点击；目标清空后仍可切回当前窗格。
- **C3：输入法 Enter 执行动作。** 命令面板在原生 `isComposing` 或 `keyCode=229` 时不执行动作、不移动动作选择。应用级测试确认组合期间零发送、面板保持打开，随后普通 Enter 只发送一次。
- **C4：中文变量被拒绝。** 模板变量名接受 Unicode 标识符，支持 `{{目录:/tmp}}`，保留原有默认值和重复变量规则。覆盖保存、默认值、修改、取消与回车；填写结果不回写片段。
- **同路径补充修复。** 变量值和分组名在事件回调内先取值，再进入 React 状态更新，避免延迟读取已清空的 `currentTarget`。模板只读取填写对象的自有属性，不把 `constructor` 等原型属性当作变量值。
- **格式结论更正。** 上版“本轮 Rust 文件单独检查通过”的表述不适用于当前 Rust 1.96.0 工具链。已修正审查指出的 `envelope.rs`、`snippet_commands.rs` 导入及 Core 片段测试格式；未格式化无关代码段。

## 修改内容

- Vault 新增加密片段和分组数据、长度与引用校验、revision 保护的保存/删除操作及备份预览和合并支持。旧 schema-0 Vault 迁移时新增字段默认为空，并覆盖迁移后重新封装的回归测试。
- Core 与 Tauri 增加受控的片段和分组命令。操作受 Vault 解锁状态及 revision 限制，不把片段复制到明文设置。
- UI 增加片段管理、分组、搜索、`{{变量}}` / `{{变量:默认值}}` 填写、取消、当前窗格或已选广播目标、可选回车。发送使用现有有界输入队列；广播多行输入先确认，目标为空时阻断，部分失败会列出目标且不自动重放。
- 增加显式注册的命令面板动作，可搜索已保存主机、片段和应用操作；`Ctrl+Shift+P` 打开面板，不将搜索文本转为命令或进程参数。主题动作无需解锁 Vault。
- 主题动作可原地更新现有 xterm 调色板，不重启 shell；pane 状态在 session 更新、分屏和重启时保留主题覆盖。补充 session 与 workspace 回归测试。
- 中英文界面文案、Vault DTO 及模板/命令动作契约测试同步增加。

## 维护者手测

1. 开发模式从关闭的片段面板出发，经命令面板运行一次无变量、自动回车的片段；确认只执行一次，再关闭并重复。
2. 中文输入法搜索片段时用 Enter 确认候选字；确认面板未关闭、终端零发送；结束组合后明确执行一次。
3. 广播目标之一退出后运行片段，确认面板内立即显示失败窗格及不重放提示；检查成功窗格只收到一次。
4. 测试广播多行确认、取消和附加回车；清空广播目标时应显示阻断原因，并能切回当前窗格。
5. 保存 `cd {{目录:/tmp}}`，测试默认值、修改、取消；改分组名后重启，确认模板、分组、回车开关保留。
6. 用命令面板搜索主机、片段及已注册操作；锁库后切换主题，核对运行中的 shell 屏幕和进程保持。
