## 修改内容

- Core 新增更新策略与有界 HTTP 下载：固定 HTTPS 端点、仓库与安装包版本绑定、Windows x64、严格递增稳定版本、清单 64 KiB、说明 16 KiB、安装包 200 MiB。校验 minisign 包签名、全局签名和受签版本；下载用临时文件，错误与取消清理暂存文件。
- Tauri 固定 updater 2.14.1，仅注册 main 窗口的自定义命令；不新增插件权限，不改变 CSP。使用 `restore_update` 交接已校验清单；安装前 SDK 再次验签。共享 SDK 配置覆盖默认的提前清理回调，启动拒绝时保留应用、窗口和 WebView 资源，成功启动后由 SDK 退出进程。NSIS 使用 passive 模式，重启不重放原启动参数。
- 更新默认手动检查，可选启动时每 24 小时至多一次；检查节流独立存储，设置沿用原子写入与 16 KiB 上限。安装需确认，活动会话/文件操作额外确认，交接前再次检查活动状态；随后走现有退出与传输恢复保存流程。
- UI 增加双语设置、纯文本发布说明、下载进度、取消和可重试错误。便携版只有提示，没有安装入口；Rust 同样拒绝其安装请求。
- 受保护的 tag 发布作业对已经验证的原安装包签名，生成 `.sig` 与 `latest.json`。发布脚本用配置公钥和 OpenSSL 验证包、签名与受签版本，上传后继续核对 GitHub SHA-256；验证作业拒绝接收签名私钥。
- NSIS hooks 在更新前备份安装目录，提交前用内嵌 SHA-256 清单核对程序与全部资源。清单由实际构建二进制和 Tauri 资源映射生成；拒写、缺失、篡改、校验器不可用均阻断提交并保留备份，不依赖可能被模板重置的错误标志。隔离脚本包含真实 `File` 拒写、正常对照、同长度篡改、校验器缺失和旧程序启动。
- 更新覆盖前记录新增路径清单，回滚删除新包新增的受管文件（含生成的 `uninstall.exe`），只移除本次新增且为空的目录。删除前校验全部记录和路径，备份已有的文件不可删除；保留用户文件、原有空目录及写入后出现的非受管内容。独立内嵌回滚脚本不依赖提交校验器仍在；重复回滚安全，恢复或清理失败时保留备份。
- 本次在提交前重新生成卸载程序，立即检查写入失败，阻断模板 `${GetSize}` 清除旧错误标志造成的误提交。回滚改为逐文件恢复并比对 SHA-256；已与备份一致的文件不写入，单个文件受阻仍恢复其余文件，最后报告失败并保留备份。清单及完整备份树先校验路径和 reparse point，之后才恢复。
- 启动拒绝探针直接引用生产 SDK 配置，复用工作区锁定版本，在独立的临时 MockRuntime crate 中连续两次验签并触发真实 Windows 启动失败；检查应用、窗口、WebView 资源保留且销毁计数为零。只生成一次性测试密钥，不调用生产安装器。
- 高对比度补系统色、边框和焦点；reduced-motion 下停止过渡与动画。沿用现有浏览器布局脚本，新增 forced-colors/reduced-motion 和更新弹窗场景；同步契约、更新安全说明、README、SECURITY、board 与 M4 收尾清单。

## 已知风险与未决问题

- 维护者尚未提供生产公钥、配置受保护的 `release` Environment/secret；当前构建没有更新网络检查或安装能力。正式 tag 的签名上传流水线尚未在 GitHub 执行。
- 隔离故障脚本验证了真实 NSIS hooks，不等同于两个生产签名版本之间的完整升级。真实安装版升级、安装中断、卸载与 registry 版本一致性仍待干净普通用户环境验收；本次未运行 `Test-M1Install.ps1`。
- 断电或强杀安装器无法执行恢复回调；恢复复制、私有清单读取或新增路径清理也可能因磁盘/权限失败。保留的同级备份用于人工恢复，步骤见 [UPDATES](../UPDATES.md)；仅覆盖复制备份不能保证清除残留新增文件。
- 安装器启动拒绝时保留 Tauri 资源，可读取错误并再次更新。交接前已按确认结束的会话不会自动恢复，重新连接前仍需重启当前程序；不会回放输入或写入 Vault。
- 校验和恢复使用 Win11 自带的 Windows PowerShell 5.1；覆盖前脚本不可用则终止，写入后脚本或恢复失效时保留备份人工恢复。MockRuntime 证明资源保留与重试，不等于真实 WebView2 窗口可见性验收。
- 浏览器模拟验证不代替真实 Win11 高对比度、辅助技术和 WebView2 键盘手测；M4-1 至 M4-4 的设备验收按 [收尾清单](M4-CLOSEOUT.md) 继续。

## 维护者手测

1. 当前构建打开软件更新，确认提示未配置公钥且检查/安装不可用；便携版不出现安装入口。
2. 配置真实公钥后，手动检查新版本；确认说明为纯文本，同版本不提示安装。
3. 有活动本地/SSH 会话及传输时确认额外提示；取消后保持运行，继续后检查恢复记录与重启。
4. 下载中断网、取消后重试；对错误签名/换钥版本确认不会进入安装器、当前程序与数据保持可用。
5. 在干净普通用户环境测试 passive 更新中的文件占用、启动拒绝和新增 DLL/目录后的失败，确认旧文件恢复、新增受管内容清除、用户文件及备份保留、窗口错误可读且可重试；再执行真实旧版→新版升级，核对数据与旧版本启动。
6. 开启 Win11 高对比度、关闭动画，只用键盘操作设置和更新弹窗，检查焦点、进度、错误与 Esc。
7. 更新时占用旧卸载程序，检查非零退出、旧程序/DLL/卸载器与备份保留；正常升级后检查卸载器更新并能完整卸载。
